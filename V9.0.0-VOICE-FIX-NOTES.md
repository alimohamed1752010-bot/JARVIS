# JARVIS V9.0.0 Voice Fix

The original V9 voice build used `@discordjs/voice` 0.18.x. Discord voice support has since moved to 0.19.2, with DAVE becoming required and Node 22.12+ required. The new build pins the current stable voice package line, includes `@snazzah/davey`, adds voice state/debug tracing, uses `entersState`, and retries transient signalling failures up to three times.

Railway must redeploy with a fresh dependency install and Node 22.12+.

Environment:
- VOICE_ENABLED=true
- GEMINI_API_KEY=...
- GEMINI_TTS_MODEL=gemini-2.5-flash-preview-tts
- JARVIS_TTS_VOICE=Kore

# JARVIS Vault Index

This is JARVIS's local, human-editable memory and instruction map. JARVIS should retrieve only relevant notes instead of loading the entire vault.

## User
- `user/profile.md` - durable profile information the user explicitly chooses to store.
- `user/preferences.md` - durable interaction and PC preferences.

## Projects
- `projects/jarvis.md` - JARVIS architecture, goals, versions and known issues.

## Instructions
- `instructions/pc.md` - PC control rules and safe tool usage.
- `instructions/spotify.md` - Spotify playback/control procedures.

## Memory
- `memory/recent.md` - durable recent events and decisions.

## Knowledge
- `knowledge/` - optional user-maintained reference notes.

# JARVIS V8.3.2 — OWNER ROUTER HARDENING

## Fixed

### `liveDiscordContext is not defined`
V8.3.1 still called a helper that was never present in the project. The owner-tool router now has no dependency on that missing symbol.

### Tool failures no longer kill JARVIS
`handleOwnerToolRequest()` is now wrapped in a defensive error boundary. If a deterministic tool or moderation parser throws, JARVIS logs the error and continues into its normal conversational AI path.

The message handler also has a second defensive boundary around the owner-tool call.

## Expected routing

- `jarvis move Oraby to Mod Chat` → voice move executor
- `jarvis disconnect Maro` → voice disconnect executor
- `jarvis time Maro out for 1 minute` → 1-minute timeout executor
- `jarvis what 1+1` → calculator
- `jarvis who's Michael Jackson?` → normal conversational AI
- `jarvis are you dumb?` → normal conversational AI

## Regression protection

The existing `safeMath()` helper remains the calculator implementation. No undefined `calculateSimpleMath` reference is introduced.

Voice move/disconnect remain separate moderation actions and continue using Discord's `Move Members` permission and hierarchy checks.

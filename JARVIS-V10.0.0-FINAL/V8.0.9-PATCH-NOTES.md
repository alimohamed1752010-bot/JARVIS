# JARVIS V8.0.9 — Roast Mode AI Fix

- Stable Gemini defaults/fallbacks: gemini-2.5-flash-lite -> gemini-2.5-flash -> latest aliases.
- Non-master mode must understand the request before roasting it.
- Removed the misleading canned `I've understood you...` fallback.
- Local fallback now references the actual request instead of pretending Gemini succeeded.
- Health version updated to 8.0.9.

Recommended Railway variables:
`GEMINI_MODEL=gemini-2.5-flash-lite`
`GEMINI_FALLBACK_MODEL=gemini-2.5-flash`


## 6-Model Fallback Upgrade
- JARVIS now supports a primary model plus six independently configurable fallback models.
- Configure `GEMINI_FALLBACK_MODEL_1` through `GEMINI_FALLBACK_MODEL_6` in Railway.
- Duplicate model names are automatically removed.
- Invalid, overloaded, rate-limited, unavailable, and timed-out models are skipped when eligible.

# JARVIS V8.3.0 — Voice Moderation

## Added
- Natural-language voice disconnects:
  - `jarvis disconnect Steve`
  - `jarvis disconnect Steve from VC`
  - `jarvis kick Steve from voice`
  - `jarvis pull Steve out of VC`
  - `jarvis get Steve out of voice`
- Natural-language voice moves:
  - `jarvis move Steve to Gaming`
  - `jarvis move Steve into General`
  - `jarvis put Steve in Gaming VC`
  - `jarvis send Steve to Lobby`
  - `jarvis move Steve from Lobby to Gaming`
- `/disconnect user reason`
- `/move user channel reason`
- Voice channel matching by exact name, partial name, or channel mention.
- Ambiguous destination names now produce a clarification instead of guessing.
- Bot-side `Move Members` permission checks.
- Voice actions are logged as their own moderation case actions.

## Separation
Voice disconnect and voice move are separate from:
- Discord timeout
- text mute role
- server voice mute

They no longer fall through to the timeout/mute executors.

## V8.3.1 HOTFIX — OWNER TOOL CRASH

Fixed a startup/runtime regression in the owner natural-language handler where `calculateSimpleMath` was referenced but no longer defined/imported. This caused **every** `jarvis ...` request to crash before moderation or normal AI handling could run.

- Restored calculator integration through the existing V8 `safeMath` helper.
- Natural-language moderation can now reach the voice disconnect/move executors.
- Normal questions such as `jarvis whos Michael Jackson` and conversational messages can continue to the appropriate handlers instead of dying on a `ReferenceError`.

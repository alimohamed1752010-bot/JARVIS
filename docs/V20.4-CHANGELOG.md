# JARVIS V20.4

## Local voice + PC bridge fixes

- Fixed deterministic `close / quit / exit` routing to `pc_close_app`.
- Added Windows process-alias closing so apps such as Spotify can be closed even when Start Menu discovery cannot find them.
- Fixed voice FFmpeg recording shutdown by using the stdin `q` command, preserving the known-good WAV finalization path.
- Removed the voice client busy lock so Right Ctrl can be used again immediately after each command.
- Fixed empty `/voice` responses by falling back to JARVIS conversational AI when the action planner intentionally returns `handled: false`.
- Voice no longer says `Done.` for an empty server response.
- Preserved Spotify play/pause/resume controls and local faster-whisper/Kokoro STT/TTS.
- Preserved PC + Discord routing and the existing owner identity/permission model.
- Invalid volume values are no longer silently clamped by plan normalization; Windows now returns the real `0-100` validation error.

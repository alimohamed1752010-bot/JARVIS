# JARVIS V20.2 - LOCAL VOICE

## Voice architecture

- Preserves the working V19 Right Ctrl keyboard watcher and FFmpeg microphone recorder.
- Replaces routine Gemini STT with local `faster-whisper`.
- Replaces routine Gemini TTS with local Kokoro TTS.
- Keeps Gemini available to the main JARVIS reasoning/Discord system; it is no longer required for every spoken PC command.
- Loads the local voice models once in a persistent Python worker instead of starting a model for every command.
- Full JARVIS execution logs remain in the console.
- Voice output is generated separately and is intentionally concise, e.g. `Opened Spotify.` instead of reading the execution report.
- Verified failures are spoken as failures instead of being presented as successful actions.

## First-run behavior

The first local-voice setup downloads the Whisper/Kokoro model files. Later voice runs use the local models. `setup-local-voice.ps1` creates `.voice-venv` and installs the required Python packages.

## Defaults

- STT model: `base.en`
- STT device: CPU / INT8 for the widest Windows compatibility
- TTS: Kokoro British English `bm_george`
- TTS speed: `1.05`

The STT device can be changed with `JARVIS_STT_DEVICE=cuda` if the machine has a working CUDA/cuDNN environment for CTranslate2.

# JARVIS V18.6

## Spotify playback execution
- `play <track> on Spotify` now searches the desktop Spotify client, attempts to select a matching result, starts playback, and verifies the Windows media session before reporting success.
- If playback cannot be verified, JARVIS reports the failure instead of claiming success.
- Added Spotify transport commands: pause, play/resume, and toggle behavior through the active Spotify media session.
- Existing V18.5 natural-language Spotify parsing and V18.3 PC + Discord systems are preserved.

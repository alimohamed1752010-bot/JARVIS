# JARVIS V20.6

- Push-to-talk now interrupts active TTS playback before recording, preventing overlapping audio layers.
- Added targeted STT normalization for the recurring “time out Oraby” recognition failure.
- Added Oraby/timeout phrases to the local Whisper prompt.
- Increased Whisper beam search and tightened VAD settings for short commands.
- Simple PC voice actions execute locally first, avoiding stale remote confirmation plans for desktop-only commands.
- Internal JARVIS execution/plan reports are filtered before TTS instead of being spoken verbatim.

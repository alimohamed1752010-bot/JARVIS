# JARVIS V20.8 — Discord Action Recovery + Voice Safety

## Discord fixes
- Fixed `time <member> out` being swallowed by the mixed-command timeout extractor when it was the entire request.
- `time Oraby out` now reaches the deterministic Discord timeout planner instead of falling through to the clock/conversation fallback.
- Fixed `yes` / `no` confirmation replies: pending V11 plans are consumed before AI conversation.
- Added broader confirmation vocabulary (`yes`, `confirm`, `proceed`, `go ahead`, `execute`, `no`, `cancel`, `stop`, `abort`).
- Preserved the legacy V9 confirmation path as a fallback.

## Local voice fixes carried forward
- Right Ctrl starts a new command generation and invalidates older in-flight voice responses.
- Old TTS generated after a new command can no longer start playback.
- Expanded Oraby STT normalization and Whisper prompt examples.
- Increased Whisper beam/best-of decoding and tightened VAD.

## Architecture
- Existing Discord natural-language planner, resolver, executor, snapshots, journal, AI conversation, PC bridge, Spotify, role/channel tools, and voice systems remain intact.

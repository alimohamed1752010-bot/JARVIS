# JARVIS V18.7

## Spotify safety and playback

- Removed the blind repeated `TAB` + `ENTER` playback loop from V18.6.
- Spotify playback now uses a short deterministic search sequence, then a Windows UI Automation lookup for the requested result and its Play button.
- The automation only invokes an accessible Play button associated with the requested result. It does not blindly press keys or click coordinates.
- If the requested result or safe Play button cannot be identified, JARVIS stops and reports failure instead of continuing to send input.
- Playback is still verified through the Windows media session before success is reported.
- Added bare `pause`, `stop`, `play`, `resume`, and `continue` transport commands when they match the Spotify-control grammar.
- Existing V18.6 PC, Discord, awareness, browser, app/game, volume, and natural-language routing remain intact.

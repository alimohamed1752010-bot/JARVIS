# JARVIS V18.8

## Multi-action PC + Discord routing fix

Built directly from V18.7.

### Fixed
- `open facebook and tiktok` now creates two ordered browser-navigation actions instead of only opening the first site.
- `open tiktok then time oraby out for 1 minute` now preserves both actions in one plan: open TikTok first, then apply the Discord timeout.
- Explicit terminal timeout clauses are extracted before PC parsing so the desktop planner cannot swallow Discord moderation actions.
- Mixed PC + Discord plans request the normal moderation confirmation for the timeout action.
- Existing V18.7 Spotify safe playback/control behavior is preserved.

### Safety
- No changes to Spotify's safe playback interaction logic.
- No blind keyboard/mouse exploration was added.
- Discord moderation still resolves members and checks actual Discord permissions/hierarchy before execution.

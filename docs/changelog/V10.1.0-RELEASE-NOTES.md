# JARVIS V10.1.0 — Maintenance Release

No commands, features, or behavior were removed or changed in this release. Every V10.0.0 feature (text intelligence, moderation, permissions, memory, resolver, journal, scheduler, dashboard, AI systems, and one-way British TTS) is unchanged. This release only fixes internal issues and documentation.

## Fixes

- `npm test` previously only ran `test/v9-core.test.js`. It silently skipped `test/v10-tts.test.js`, which is the suite that actually verifies the identity fix (`who am I` routing) and the TTS-only guarantee (no STT/voice-receive code). `npm test` now runs the full `test/` directory, so both suites execute every time.
- Removed `src/v10-tts.tmp`, a stray empty file left over in the source tree with no code referencing it.

## Documentation

- `README.md` now has a V10 section describing text-intelligence and TTS instead of stopping at V9.0.0.
- Corrected the Railway/voice environment variable examples in `README.md`, which listed `GEMINI_TTS_MODEL=gemini-3.1-flash-tts-preview` and `JARVIS_TTS_VOICE=Kore` — neither matches what the code actually defaults to (`gemini-2.5-flash-preview-tts` and `Algenib`, per `src/v8/voice.js` and `.env.example`). Anyone following the old instructions would have configured the wrong model and voice.
- `.env.example` now documents `DEPLOY_ONLY`, which `src/deploy-commands.js` sets internally but was previously undocumented.
- Historical `V8.x`/`V9.x` patch and release notes, plus `V4-SETUP.md`, moved into `docs/changelog/` so the repo root only shows current documentation (README, AI-RAILWAY-SETUP, and the two latest release notes files).

## Version

`package.json` bumped from `10.0.0` to `10.1.0`. The version assertion in `test/v10-tts.test.js` was updated to match.

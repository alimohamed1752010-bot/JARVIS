# JARVIS V8.1.1 — V7.4 Conversation Patch

This build keeps the V8 infrastructure but restores the parts of the V7.4 conversation behavior that made JARVIS feel more natural.

## Conversation fixes

- Non-master conversations use a fresh request-focused AI context instead of feeding old roast output back into the next roast.
- Non-master replies explicitly understand the request first, then make the requester the punchline.
- Generic clearance/denial responses are no longer the normal fallback personality.
- Owner conversations keep their persistent V8 session continuity.
- Owner roast requests are kept separate from normal conversation memory.
- V7.4-style temperature/output defaults are restored for more natural, punchy replies.
- Removed speculative Gemini 3.x fallback model names; fallback defaults are limited to known V8 model names.
- V8 sessions, summaries, usage tracking, rate limiting, tools, voice, and Railway support remain intact.

## Expected behavior

`jarvis whos micheal jackson` from a non-master should produce a custom roast about asking JARVIS that question, rather than answering it or returning a generic denial.

`jarvis insult @someone` from the master should roast the named non-master target.

`jarvis ...` from the master should answer normally and remember the conversation.

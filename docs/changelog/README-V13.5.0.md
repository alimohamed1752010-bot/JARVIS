# JARVIS V13.5.0 — SUPERIOR

V13.5 adds a persistent learning layer and safer proactive monitoring on top of V13.

## Highlights
- Observed server behavior profiles with bounded retention.
- Persistent anomaly history.
- Autopilot detection for join bursts, rapid role-permission changes, channel/role deletion, and bans.
- Autopilot remains alert-only: it does not automatically perform destructive actions.
- Learned behavior is injected into the agent as observed context and is explicitly treated as non-authoritative.
- Existing natural-language agent, planning, validation, snapshots, rollback, verification, six-model fallback, Tony Master Mode, Roast Mode, and DM reply continuity are retained.

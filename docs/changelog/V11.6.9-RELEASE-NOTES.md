# JARVIS V11.6.9 — SUPERIOR

## Core upgrade
V11.6.9 introduces the Superior Agent Engine: natural-language Discord administration is converted into a structured, bounded plan, validated against Discord permissions/hierarchy, executed through safe tools, and reported step-by-step.

### Examples
- `jarvis move everyone in gen 1 to gen 2 except Steve`
- `jarvis change the @Moderators perms to remove soundboard access`
- `jarvis create a staff channel called operations, then create a Staff role`
- `jarvis give @VIP to Steve and rename #general to lobby`

## Safety
- Owner-only execution remains enforced.
- High-impact plans require explicit `yes` confirmation.
- Discord bot permissions and role/channel hierarchy are checked.
- Managed/integration roles are protected.
- AI produces plans only; it cannot execute arbitrary code.
- Unknown actions are rejected.
- Plans are capped at 12 steps and individual target lists are bounded.

## New agent actions
- Voice move/disconnect/mute/deafen
- Text mute/unmute
- Timeout/untimeout
- Kick/ban/warn
- Role permission changes
- Add/remove roles
- Rename/create/delete channels
- Create/delete roles
- Member nicknames
- Channel permission overwrites

## Reliability fixes
- Fixed undefined executor variables for role/channel operations.
- Corrected V10/V9 audit labels to V11.
- Added deterministic confirmation handling for pending V11 plans.
- Added strict JSON planning and sanitization.

# JARVIS V8.2.2 — Natural Command Resolution Fix

- Natural owner commands now resolve members by exact username/global/display name before partial matching.
- `jarvis timeout Steve` works without a mention and defaults to 10 minutes.
- `jarvis timeout Steve for 30 minutes` parses the duration.
- `jarvis Steve is spamming, handle it` resolves Steve safely and infers a 10-minute timeout.
- `jarvis insult Steve` resolves Steve naturally for the owner roast pipeline.
- `jarvis untime out Steve` / `jarvis untimeout Steve` removes the timeout.
- Ambiguous partial member matches are not guessed.
- Prevents the previous wrong-member resolution such as handling `imlop` when `Steve` was requested.
- All JS files pass Node syntax validation.

# JARVIS V8.1.0 — Ultimate Hybrid Conversation + Roast Mode

V8.1.0 combines the strongest conversation/roast behavior from V7.4 with the resilience and AI architecture from V8.0.9.

## Conversation / Roast improvements
- Restored V7.4's explicit **understand → answer/roast appropriately → keep the response contextual** conversation contract.
- Master/Tony mode stays loyal, warm, helpful, and never insults Tony.
- Non-master mode is a dedicated roast mode: it understands the actual request first, then makes the requester the punchline without answering the request.
- Roast behavior is request-aware for questions, greetings, insults, calculations, help requests, and roast requests.
- Arabic/Egyptian Arabic requests are explicitly supported in the personality contract.
- Personality modes remain available: `classic`, `professional`, `sarcastic`, `strict`, `chaotic`.
- Non-master conversation history is capped more tightly so previous normal-looking answers cannot accidentally pull the model out of roast mode.

## V8 infrastructure retained
- Six configurable Gemini fallback slots.
- Primary + legacy fallback + six additional fallbacks, with duplicate removal.
- Automatic fallback on model-not-found, rate-limit, overload, temporary-unavailable, timeout, and server errors when eligible.
- Persistent per-user conversation sessions and summaries.
- AI request locks, throttling, usage tracking, health diagnostics, tools, dashboard, and optional voice.

## Railway
Keep your existing variables. The six fallback variables remain:
`GEMINI_FALLBACK_MODEL_1` through `GEMINI_FALLBACK_MODEL_6`.

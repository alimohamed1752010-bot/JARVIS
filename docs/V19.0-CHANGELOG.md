# JARVIS V19.0

## Push-to-talk voice
- Hold **Right Ctrl** to record from the Windows microphone.
- Release **Right Ctrl** to transcribe the recording with Gemini STT.
- The transcript is sent to the existing JARVIS planner using the configured owner and Discord guild identity.
- JARVIS replies through Gemini TTS and plays the response locally.
- Existing Discord, PC, Spotify, confirmations, and mixed-action routing remain in the V18.8 base.
- No wake word and no always-listening mode in V19.0.

## Safety / failure behavior
- The microphone records only while Right Ctrl is held.
- The voice layer does not bypass JARVIS permissions or confirmation plans.
- If the microphone cannot be detected, setup stops instead of silently selecting an unknown input.
- If transcription or command execution fails, JARVIS speaks the failure rather than claiming success.

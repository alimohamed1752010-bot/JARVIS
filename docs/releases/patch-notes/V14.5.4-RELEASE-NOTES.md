# JARVIS V14.5.4 — SUPERIOR ACTION FIX

## Fixed
- Natural-language role creation now understands phrases such as `soundboard access perms`.
- Owner-directed role creation + assignment no longer gets incorrectly diverted to conversational fallback for this supported permission request.
- Channel resolution now normalizes `_` / `-` punctuation and supports common shorthand such as `sec 1` → `secret 1` and `gen 2` → `general 2`.
- The V14.5.3 planner-null conversational fallback is retained.

## Regression coverage
- Soundboard permission normalization.
- Deterministic role-create + role-assign planning.
- `sec 1` channel resolution.

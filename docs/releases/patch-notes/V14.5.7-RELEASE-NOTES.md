# JARVIS V14.5.7 — SERVER REPLY TRIGGER FIX

## Fixed
- Replying directly to a JARVIS message in a server now wakes JARVIS without requiring `jarvis` or a mention.
- The server reply trigger is restricted to `JARVIS_OWNER_ID`.
- JARVIS only wakes when the referenced message was actually authored by the bot.
- Uses Discord.js `fetchReference()` so the trigger is not dependent on the referenced message already being cached.
- Direct server replies now pass through the V11 agent first, then the normal conversational/tool pipeline.
- Existing explicit `jarvis ...` triggers remain unchanged.
- Existing DM direct-reply behavior remains unchanged.

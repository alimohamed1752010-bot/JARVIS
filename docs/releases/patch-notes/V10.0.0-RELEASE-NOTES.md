# JARVIS V10.0.0 — Text Intelligence + TTS

V10 preserves the V9 command, moderation, permissions, memory, resolver, journal, scheduler, dashboard, and AI systems. Voice is intentionally one-way: JARVIS reads Discord text and speaks its own responses. There is no STT, microphone receiving, voice transcription, or Discord audio receiver.

## Voice
- British male-oriented Gemini TTS profile using configurable prebuilt voice.
- Default voice: `Algenib`.
- Default language/accent intent: `en-GB`.
- Per-guild TTS queue prevents overlapping playback.
- Automatic TTS for JARVIS text replies.
- `jarvis voice`, `jarvis voice on`, `jarvis voice off`, `jarvis voice stop`, `jarvis voice pause`, `jarvis voice resume`, `jarvis voice status`, `jarvis voice leave`.
- TTS failure never prevents the Discord text reply from being delivered.
- Voice diagnostics report connection, player, queue, model, voice and accent configuration.

## Safety / compatibility
- Existing V9 files are retained and used as the core.
- STT/voice-receive code was removed from the active V10 voice module.
- `prism-media` and `opusscript` are no longer required.


## V10.0.0 hotfixes
- Added deterministic `who am I`, `who is me`, and `what is my username` handling.
- These identity queries now use the authenticated Discord message member directly and never enter the moderation/member-target resolver.
- TTS hook now prefers the voice service's active connection, reducing stale guild-property failures.
- Voice remains output-only: no STT, microphone receiving, or voice receiver.


## Post-V10 hardening included in this build
- Fixed natural-language voice move parsing for `everyone in <source> to <destination> except <member>`.
- Added AI-routed role permission changes, role assignment/removal, and channel renaming with Discord hierarchy/permission checks.
- Added human-readable permission aliases such as `soundboard`, `send messages`, and `manage messages`.
- Added confirmation before AI-directed role permission changes.
- Added strict rejection of unknown AI command actions.
- Re-ran syntax checks across every JavaScript source/test file and the existing test suite.

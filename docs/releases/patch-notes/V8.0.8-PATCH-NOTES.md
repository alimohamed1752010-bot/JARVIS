# JARVIS V8.0.8 — Roast Mode / AI Reliability Fix

## Fixed
- Non-master users no longer receive the exact same generic fallback sentence for unrelated questions.
- Added deterministic, message-aware local roast fallbacks when Gemini is unavailable, overloaded, rate-limited, times out, or otherwise fails.
- Movie/release-date questions now get a distinct contextual roast fallback instead of the old generic "disturb my master" line.
- Updated default Gemini models to current stable, production models:
  - Primary: `gemini-3.6-flash`
  - Fallback: `gemini-3.5-flash-lite`
  - Legacy 2.5 models remain as final fallback candidates.
- Bumped bot version to `8.0.8`.

## Railway
Recommended variables:
- `GEMINI_MODEL=gemini-3.6-flash`
- `GEMINI_FALLBACK_MODEL=gemini-3.5-flash-lite`

You still need your existing `GEMINI_API_KEY` and `JARVIS_OWNER_ID`.

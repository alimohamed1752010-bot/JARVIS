# JARVIS V14.5.2 — Superior Command Reliability & Undo Fix

## Fixed
- Deterministic Superior-agent parsing for common natural-language server commands when the AI planner returns empty/invalid JSON.
- Voice moves: `move me to gen 2`, `move me n Steve to sec 1`, and `move everyone in gen 1 to gen 2 except Steve`.
- Channel creation with parent categories, including the common typo `catagory`.
- Channel type preservation through plan validation.
- Optional automatic creation of a requested parent category when it does not exist.
- Deterministic `undo` handling so it never depends on the AI planner.
- Reversible journaling for role assignment, role creation, and channel creation.
- Multi-step plan undo reverses successful reversible steps in the correct order.
- Undo operations no longer create a new journal entry that immediately becomes the next undo target.
- Undone journal entries are marked as `UNDONE` and are not reused as active undo targets.

## Validation
- All 18 existing automated tests pass.
- JavaScript syntax checks pass for the modified core files.

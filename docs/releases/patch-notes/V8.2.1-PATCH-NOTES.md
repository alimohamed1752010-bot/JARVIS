# JARVIS V8.2.1

- Fixed owner roast validation so numeric/rating/acknowledgement outputs such as `-2, sir.` cannot be sent.
- Added natural-language owner moderation. JARVIS can resolve a named or mentioned member, infer a conservative moderation action from the reported behavior, infer duration, and execute it.
- Example: `Jarvis, Steve is spamming, handle it` resolves Steve and applies a 10-minute timeout by default.
- Explicit moderation actions remain supported.
- Safety: JARVIS never moderates the configured owner, the server owner, or itself; Discord hierarchy/permissions are checked.
- Natural-language actions are logged as moderation cases.

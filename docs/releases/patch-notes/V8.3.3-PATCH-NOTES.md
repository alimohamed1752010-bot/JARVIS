# JARVIS V8.3.3 — Voice Move Clarification Fix

## Fixed
- `gen 1` now normalizes to `general 1`, so common VC shorthand works.
- Ambiguous voice destinations now create a short-lived pending selection tied to the owner and guild.
- A plain follow-up such as `general 1` can complete the pending move without the `jarvis` prefix.
- Pending selections expire after 60 seconds.
- Selection is restricted to the channels presented by JARVIS, preventing unrelated channel matches.
- Exact channel-name matches are preferred over partial matches.
- Voice move execution still uses the existing Move Members permission and Discord hierarchy checks.

## Examples
- `jarvis move Oraby to gen 1` → resolves `gen 1` as `General 1`.
- `jarvis move Oraby to general 1` → resolves exact `General 1`.
- `jarvis move Oraby to general` → if multiple channels match, JARVIS asks for a choice; replying `general 1` completes it.

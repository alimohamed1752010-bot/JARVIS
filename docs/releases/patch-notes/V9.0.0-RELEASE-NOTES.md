# JARVIS V9.0.0 — Intelligent Command System

V9 is an architecture release. Natural language, slash commands, and legacy commands can now converge on reusable resolution, permission, execution, journaling, and diagnostics layers.

## Core
- Universal command engine
- Universal member/channel resolver with ambiguity handling
- Central permission and role-hierarchy checks
- Action executor for voice and moderation operations
- Short-lived multi-turn command context
- Confirmation workflow for destructive actions
- Reversible action journal + undo
- Simulation/dry-run planning
- Live server awareness snapshots
- Event-awareness hooks for voice/channel changes
- V9 diagnostics and architecture status

## New commands
- `jarvis v9`
- `jarvis undo [case]`
- `jarvis v9simulate <command>`

## Natural language examples
- `jarvis move me n steve to gen 1`
- `jarvis move everyone from general to gaming`
- `jarvis disconnect everyone`
- `jarvis server mute steve`
- `jarvis timeout steve for 10m`
- `jarvis undo that`
- `jarvis simulate move everyone to gaming`
- `jarvis who's in general 1`
- `jarvis diagnostics`

## DM continuity
When the owner replies directly to a JARVIS message in a DM, the reply itself is treated as the invocation. The owner does not need to type "Jarvis" again.

## Safety model
AI output is treated as an untrusted plan. The bot validates actions against an allowlist, resolves real Discord entities, checks Discord permissions/hierarchy, requests confirmation for elevated-risk actions, executes through explicit tools, and verifies results.

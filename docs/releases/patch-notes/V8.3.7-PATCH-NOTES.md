# JARVIS V8.3.7 — Voice Move Routing Fix

- Fixed `gen N` destination matching so it resolves to `General N` without colliding with `Secret General N`.
- Added `sec gen N` / `secret gen N` aliases for secret general channels.
- Added robust normalization for invisible Unicode characters and spacing.
- Added self-target resolution for `move me`, `move myself`, and `move i`.
- Clarification selection continues to use the exact Discord channel ID selected from the presented options.
- Numeric clarification replies such as `1` remain supported.
- Unrelated messages are not consumed by pending voice-move clarification.

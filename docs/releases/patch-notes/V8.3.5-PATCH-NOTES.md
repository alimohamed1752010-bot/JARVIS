# JARVIS V8.3.5 - Voice Move Clarification Fix

## Fixed
- Bare clarification replies such as `general 1` and `gen 1` are accepted.
- `jarvis general 1` is also accepted while a clarification is pending.
- Numbered choices such as `1` are accepted.
- Matching is limited to the exact channels JARVIS presented.
- Normalized shorthand, spacing, punctuation, and case are supported.
- A non-answer such as `bruhhhhhhhhh` is not consumed by the pending move state.
- The selected channel is passed directly by channel ID, avoiding a second natural-language destination parse.
- Added diagnostic logging for pending voice clarification matching.
- Pending state remains scoped to guild + requesting user and expires after 60 seconds.

## Validation
- All JavaScript files pass `node --check`.

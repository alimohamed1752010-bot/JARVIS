# JARVIS V15.0.1 — Creator Identity Fix

## Identity system

V15.0.1 replaces the V15.0.0 creator reply with a centralized identity module.

### What changed

- Added `src/core/identity.js` as the single source of truth for creator identity.
- Creator verification uses the configured Discord owner ID.
- Added optional `JARVIS_OWNER_NAME` and `JARVIS_OWNER_TAG` environment values for presentation.
- Removed the explicit Tony Stark comparison from active creator responses.
- Creator questions are recognized for both master and non-master users.
- Non-master users receive the creator answer instead of the normal roast path when they ask who made/built/created/owns JARVIS.
- AI context now receives creator identity knowledge so the model can answer naturally instead of relying only on exact canned phrases.
- Existing owner protection remains ID-based.

## Documentation

- Historical READMEs moved to `docs/releases/readmes/`.
- Historical release/patch/architecture notes moved to `docs/releases/patch-notes/`.
- Setup documents moved to `docs/setup/`.
- Added this V15.0.1 release note and README.

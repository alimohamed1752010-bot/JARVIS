## Added
- Command preview/dry-run alias: `jarvis preview <command>`
- Detailed action history: `jarvis history`
- Snapshot diff with named role/channel changes: `jarvis diff snapshot`
- Incident report: `jarvis incident report`
- Case explanation: `jarvis explain case #123`
- Member profile: `jarvis profile @user`
- Server health score: `jarvis health`
- JARVIS Watch for message/mention activity spikes: `jarvis watch #channel`, `jarvis watch off`
- Persistent scheduled actions: `jarvis schedule 10m <command>`, `jarvis schedule list`, `jarvis schedule cancel <id>`
- Scheduled action completion/failure logging.

## Existing systems preserved
- V9/V11/V12 agent architecture, resolver, risk validation, snapshots, undo, event awareness, autopilot, server knowledge, memory, voice/TTS, moderation, and dashboard.

## Notes
- Preview mode performs no Discord mutations.
- Snapshot restore remains best-effort because Discord does not let a snapshot recreate every deleted object.
- JARVIS Watch is alert-only and does not automatically punish users.

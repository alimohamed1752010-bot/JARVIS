# JARVIS V12.0.0 SUPERIOR

JARVIS is a Railway-friendly Discord AI assistant with an owner-only control plane, six configurable Gemini fallbacks, conversation/roast identity modes, and a natural-language autonomous server agent.

## Railway
Set:
- `DISCORD_TOKEN`
- `JARVIS_OWNER_ID`
- `GEMINI_API_KEY`
- optional `GEMINI_MODEL`
- optional `GEMINI_FALLBACK_MODEL`
- optional `GEMINI_FALLBACK_MODEL_1` through `_6`

Run `npm start`.

## V12 capabilities
- Server Brain / live server analysis
- Multi-step natural-language agent plans
- Permission, hierarchy, and bot-authority validation
- Risk scoring and confirmation gates
- Dry-run simulation
- Post-action verification
- Persistent action journal
- Pre-plan server snapshots and best-effort rollback
- Audit intelligence
- Server Autopilot monitoring foundation
- Conversational context continuity
- DM reply continuity: replying directly to a JARVIS DM invokes JARVIS without requiring the name

The AI never receives arbitrary shell/code execution capability. Discord actions are performed only by explicit, allow-listed tools.
